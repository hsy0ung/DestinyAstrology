# 별결 · DestinyAstrology

사주와 서양 점성술의 계산 결과를 함께 참고해, 한국어 대화로 성향과 고민의 다음 행동을 정리하는 웹앱의 첫 개발 버전입니다.

## 지금 사용할 수 있는 기능

- 이메일·비밀번호 회원가입/로그인, 서버 세션, 출생 정보 저장, 최근 대화 기록, 계정 삭제
- 오전·오후와 시·분을 각각 선택하는 출생 시간 입력. 출생 시간을 모르면 별도 체크로 시주·상승점 제외
- 국내 17개 시·도의 주요 지역 27개와 해외 도시 5개 지원. 지역별 시간대와 중심 좌표 사용
- 양력 생년월일·출생 시간·지역을 바탕으로 사주 기둥과 오행, 태양·달·상승점 계산
- 성향, 사주 관점, 점성술 관점, 통합 해석, 구체적인 행동, 후속 질문을 나누는 대화 화면. 새 대화와 기존 대화의 문맥을 구분
- **일반 대화: 계정당 하루 3회 무료.** 한국 시간 자정 초기화, 무료 횟수를 먼저 사용
- **대화 이용권: 5,000원에 대화 5회.** 심화 대화 또는 무료 횟수 소진 후 사용. 자동 구독 없이 별도 구매, 현재 버전에서 만료 없음
- 서버에서 결제를 승인·검증한 주문에만 이용권 지급. 주문/결제 승인 재요청으로 중복 지급하지 않음
- 실패한 답변은 이용 횟수 반환, 동일 요청 재전송은 성공한 답변과 차감 결과 재사용

키를 설정하지 않은 기본 모드는 **예시 답변**입니다. 실제 AI가 생성한 답변처럼 표시하지 않으며, 결제도 활성화하지 않습니다. AI 응답은 클라이언트의 유료 사용량 주장을 신뢰하지 않고 서버에서 관리합니다.

## 내 컴퓨터에서 실행

Node.js **24.x**를 설치하고, GitHub에서 코드를 다운로드하거나 저장소를 복제한 뒤 **`package.json`이 있는 폴더**에서 터미널을 엽니다. Mac의 경우 Finder에서 해당 폴더를 연 다음 터미널에서 그 폴더로 이동하세요.

```bash
npm ci --cache ./npm-cache
npm run dev
```

터미널에 `Ready`가 표시되면 **터미널의 Local 주소를 본인 컴퓨터의 브라우저에서** 엽니다. 회원가입 → 출생 정보 입력 → 고민 질문 → 후속 질문 순서로 확인하세요. 기본 예시 모드는 API 키 없이 실행됩니다. 일반 대화 3회 후에는 추가 대화를 제한하고, 결제 설정 전에는 구매할 수 없습니다.

`npm ci --cache ./npm-cache`는 아래 클라우드 전용 캐시 경로를 덮어쓰는 명령입니다. Windows와 macOS에서 모두 사용할 수 있습니다. 포트가 이미 사용 중이면 `npm run dev -- --port 3001`로 시작하세요. 자동 검사는 `npm test`, 빌드 검사는 `npm run build`입니다.

## 클라우드에서 개발 시작

Node.js **24.x**와 npm이 필요합니다. SQLite는 Node 내장 `node:sqlite`를 사용하므로 별도 DB 서비스가 필요하지 않습니다.

```bash
cd /workspace/DestinyAstrology
npm ci
npm run dev
```

`npm ci`는 잠금 파일 기준으로 설치합니다. 이 클라우드에서는 `.npmrc`의 `/workspace/.npm-cache`를 사용합니다. 다른 컴퓨터에서는 필요한 경우 `npm ci --cache /tmp/destiny-npm-cache`로 경로를 지정하세요. 각 클라우드 작업은 격리되어 있으므로 기존 체크아웃을 사용하고 별도의 Git worktree를 만들 필요가 없습니다.

```bash
npm test
npm run typecheck
npm run build
npm start
```

서버가 예시 모드로 실행 중이면 `npm run test:smoke`로 실제 HTTP 흐름을 검사할 수 있습니다. 임시 계정을 생성하고 검증 후 삭제하며, 유료 AI·결제는 호출하지 않습니다.

이 클라우드에는 Chromium이 설치되어 있어 `npm run test:browser`로 데스크톱·모바일 가입·오전/오후 시간 저장·지역 선택·대화와 세 결제 수단의 SDK 호출을 검사할 수 있습니다. 결제 경계는 모의 처리하며 실결제를 하지 않습니다. 다른 머신에서는 `ASTRO_BROWSER_PATH`에 Chromium 실행 파일 경로를 지정하세요.

개발 서버와 프로덕션 서버를 동시에 같은 포트에 시작하지 마세요. `PORT=3001 npm start`처럼 포트를 지정할 수 있습니다. 준비 상태는 내부 요청 `GET /api/health`로 확인하고, 기능 검증은 회원가입 → 출생 정보 → 실제 대화 → 횟수 감소 흐름으로 수행합니다.

## AI 연결

Mac에서 실제 AI 답변을 사용하려면 API 키를 발급한 뒤 아래 명령을 실행하세요. ChatGPT 구독료와 OpenAI API 사용료는 별도입니다.

1. [OpenAI API 관리 페이지](https://platform.openai.com/)에서 프로젝트를 만들고 API 결제를 설정합니다. [API 키 페이지](https://platform.openai.com/api-keys)에서 키를 발급합니다.
2. 프로젝트 폴더에서 `npm run setup:ai`를 실행합니다. 처음에는 OpenAI를 선택하고 기본 모델을 사용하면 됩니다. API 키 입력은 터미널에 표시되지 않습니다. 키는 Git에 포함되지 않는 `.env.local`에 저장됩니다. 기존 결제·DB 설정은 유지합니다.
3. `npm run check:ai`를 실행합니다. 가상의 출생 정보와 질문으로 실제 AI 응답 1회를 요청하고 답변 형식을 검증합니다. API 사용료가 발생하며 계정 생성이나 대화 이용권 차감은 없습니다.
4. 실행 중인 개발 서버를 `Ctrl+C`로 종료하고 `npm run dev`로 다시 실행합니다. Mac 브라우저에서 터미널의 Local 주소를 열고 새 질문을 보내세요. 이전에 저장한 예시 답변은 그대로 표시되며, 연결 후 새 질문에는 실제 AI 답변이 표시됩니다.

```bash
npm run setup:ai
npm run check:ai
npm run dev
```

`setup:ai`는 OpenAI·Gemini·Claude 중 선택한 제공업체에 맞는 모델을 설정합니다. 제공업체를 바꾸면 해당 제공업체의 새 API 키를 입력해야 합니다. `check:ai`가 실패하면 오류 안내를 확인하세요. 인증 오류는 API 키와 프로젝트 권한, 사용 한도 오류는 API 결제·잔액·요청 한도를 확인해야 합니다. 연결 검증을 통과한 후 사이트 대화도 확인하세요.

호스팅에 배포할 때는 같은 변수 이름을 호스팅 서비스의 환경 변수·보안 입력에 등록합니다. `.env.local`을 GitHub에 업로드하거나 API 키를 채팅에 보내지 마세요.

`.env.example`에는 변수 이름과 기본값만 있습니다. 로컬에서는 `.env.local`, 클라우드에서는 환경 설정의 보안 입력을 사용하세요.

| 변수 | 용도 |
| --- | --- |
| `ASTRO_AI_PROVIDER` | `openai`(기본), `gemini`, `claude` |
| `ASTRO_AI_MODEL` | 선택한 공급자의 모델 ID. OpenAI 기본값은 `gpt-4o-mini` |
| `ASTRO_AI_API_KEY` | 선택한 AI 공급자의 인증 정보 |
| `ASTRO_TOSS_CLIENT_KEY` | 토스페이먼츠의 공개 클라이언트 키. 개발 중에는 테스트 키 |
| `ASTRO_TOSS_AUTH_HEADER` | 클라우드 프록시에서 그대로 전달하는 토스 HTTP Authorization 헤더 전체 |
| `TOSS_SECRET_KEY` | 일반 로컬/서버 배포에서만 사용하는 원본 토스 시크릿 키. 위 헤더 설정의 대안 |
| `ASTRO_APP_URL` | 고정된 앱 origin. HTTPS 배포 시 지정하여 요청 origin과 세션 보안을 검증 |
| `ASTRO_DB_PATH` | 영속 SQLite 파일 경로. 기본값 `.data/astro.sqlite` |

AI에는 계산된 차트, 현재 질문, 최근 대화 일부를 전송합니다. 출생자의 이름·정확한 생년월일·출생 시간·이메일은 AI 요청에서 제외합니다. 고민 내용에 스스로 적은 개인정보는 질문에 포함될 수 있습니다. 공급자별 HTTPS 목적지는 OpenAI `api.openai.com`, Gemini `generativelanguage.googleapis.com`, Claude `api.anthropic.com`입니다.

토스 인증은 Basic 방식입니다. 클라우드의 프록시용 비밀값은 코드가 변환하면 사용할 수 없으므로, 보안 입력에는 완성된 Authorization 헤더를 넣고 앱은 그대로 전달합니다. 일반 배포에서는 `TOSS_SECRET_KEY`를 읽어 서버에서 헤더를 만듭니다. 비밀값은 저장소·대화·브라우저에 넣지 않습니다.

## 결제 흐름

1. 로그인한 사용자가 대화 이용권을 선택하면 서버가 5,000원/5회 주문을 생성합니다.
2. 토스페이먼츠 JavaScript SDK에서 **토스페이, 카카오페이, 신용·체크카드** 중 선택한 결제를 진행합니다. 간편결제는 가맹점 계약과 상점 설정에서 활성화해야 합니다.
3. 리디렉션 후 서버가 로그인 계정의 주문, 금액, 결제키와 토스 승인 결과를 대조합니다.
4. `DONE` 상태, `KRW`, 주문번호와 금액이 모두 일치한 경우에만 한 번 지급합니다.

브라우저의 성공 URL 방문만으로 이용권이 생기지 않습니다. 실결제를 시험하지 말고 토스 테스트 환경에서 성공·취소·거절·중복 승인을 확인한 뒤 상용 인증 정보를 연결하세요. 외부 AI/토스 인증 정보가 없는 환경에서는 실제 AI 답변과 실제 결제 승인을 검증할 수 없습니다.

## 계산 범위

입력은 **양력**입니다. 음력 변환 UI는 아직 제공하지 않습니다. 연주와 월주는 절기의 실제 시각, 일주·시주는 출생지의 현지 시각과 자정 날짜 변경을 기준으로 합니다. 진태양시 보정, 지장간·용신·대운 계산은 포함하지 않습니다.

서양 점성술은 열대황도와 지구 중심 좌표를 사용합니다. 하우스·트랜싯·행성 간 각(애스펙트)는 아직 포함하지 않습니다. 출생 시간을 모르면 시주·상승점을 제외하며, 같은 날 달 별자리가 바뀌면 달 별자리도 제외합니다. 시간대의 존재하지 않거나 모호한 일광절약시간은 임의로 보정하지 않습니다.

이 서비스는 자기 성찰을 돕는 참고 해석입니다. 사주·점성술을 검증된 심리 진단이나 확정적인 미래 예측으로 제시하지 않습니다. 고위험 결정은 계산 결과만으로 유도하지 않습니다.

## 배포 전 남은 작업

현재 개발 버전은 한 서버의 영속 SQLite 저장소를 기준으로 합니다. 서비스 공개 전에는 이메일 인증/비밀번호 재설정, 실제 운영 데이터의 백업·복구, 분산 요청 제한, 개인정보 처리방침과 이용약관, 결제 환불·취소·구매 이력 및 회계 보관 정책을 연결해야 합니다. 현재 계정 삭제는 계정·출생 정보·대화·이용권과 로컬 주문을 삭제합니다.

실행 프로세스는 환경 게시 후 자동으로 살아 있지 않습니다. 저장된 `start_skill`의 시작/검증 명령으로 재시작해야 합니다. 환경 설정 초안 저장, 환경 게시, GitHub 원격 반영과 공개 서비스 배포는 각각 별도입니다.
